# 测量算法使用指南

> 适用算法：圆弧拟合（Arc Fit）、卡尺（Caliper）、角点检测（Corner Detect）、Blob 分析（Blob Analysis）、黄金模板（Golden Template）

---

## 一、圆弧拟合（Arc Fit）

### 功能说明

从图像中精确提取圆弧的圆心、半径、弧长、弦长和角度范围。  
算法流程：**环形扇形 ROI → 径向扫描线 → 亚像素边缘点云 → RANSAC 圆拟合**。

### ROI 设置

Arc Fit 使用**环形扇形 ROI**（最适合圆弧形状）：

| ROI 参数 | 含义 | 调整建议 |
|----------|------|----------|
| Center X / Y | 扇形圆心坐标（像素） | 粗略设置到目标圆弧的圆心位置 |
| Inner R | 内半径 | 比预期半径小 20～40 px |
| Outer R | 外半径 | 比预期半径大 20～40 px |
| Start Deg | 扫描起始角度（0° = 3 点方向，顺时针） | 仅扫描圆弧所在角度范围，排除无效区域 |
| End Deg | 扫描终止角度 | 设为 360 则扫描完整圆 |

> **提示**：Inner R 和 Outer R 共同决定采样带宽，太窄会漏掉边缘，太宽会引入背景噪声。建议带宽 = 预期半径的 30%～50%。

### 扫描参数

| 参数 | 含义 | 推荐值 |
|------|------|--------|
| Scan Lines | 沿弧方向的扫描线数量 | 圆弧 ≥ 180°：36 条；局部圆弧：按弧长 /10 px 估算 |
| Edge Thr | 梯度阈值，低于此值不算边缘 | 对比度高：50～100；对比度低：15～30 |

### 拟合参数

| 参数 | 含义 | 推荐值 |
|------|------|--------|
| RANSAC Iter | 随机采样迭代次数 | 500（精度要求高时 1000） |
| Inlier Dist | 内点到圆的最大距离（px） | 亚像素场景：1.0～2.0 |
| Min Inliers | 最少内点数，不足则判 NG | ≥ Scan Lines × 0.5 |

### 输出结果

| 输出 | 说明 |
|------|------|
| 圆心 (cx, cy) | 拟合圆心坐标（像素） |
| 半径 R | 拟合半径（像素） |
| Span | 弧段跨度角（°） |
| Arc Length | 弧长（像素） |
| Chord Length | 弦长（像素） |
| Inliers | 内点数（越多拟合越可靠） |

### 典型操作步骤

1. 打开图像，选择算法 **Arc Fit**
2. 在图像上拖拽扇形 ROI 的圆心至目标圆弧中心
3. 调整 Inner R / Outer R 使黄色采样带夹住圆弧边缘
4. 若仅是局部圆弧，调整 Start Deg / End Deg 避开无弧区域
5. 点击 **▶ Run**，查看绿色拟合弧线及参数结果
6. 若内点数偏少，适当放大 Inner/Outer R 或降低 Edge Thr

### 常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| 拟合失败 / 内点数为 0 | ROI 没有覆盖边缘 | 检查 Inner/Outer R 是否夹住弧边 |
| 圆心偏差大 | 弧段太短（< 60°） | 增大 Start-End 角度范围或提高 Min Inliers |
| 把背景当边缘 | Edge Thr 太低 | 提高 Edge Thr；收窄 Inner/Outer R |
| 结果跳动 | Scan Lines 太少 | 增加 Scan Lines 到 60～100 |

## 二、卡尺（Caliper）

### 功能说明

沿一条直线路径等间距部署多个虚拟卡尺，每个卡尺垂直于路径方向扫描一段距离，找到最强边缘点。  
主要用途：
- **单边模式**：定位一侧边缘并计算直线度
- **双边模式（Width）**：同时找两侧边缘，测量工件宽度

### ROI 设置

卡尺使用**旋转矩形 ROI**（可拖拽四个角点调整大小，拖拽中心平移）：

| ROI 参数 | 含义 | 调整建议 |
|----------|------|----------|
| 矩形长轴 | 沿目标边缘方向 | 需覆盖整条待测边缘 |
| 矩形短轴（卡尺长度） | 垂直于边缘，扫描范围 | 覆盖边缘两侧各 10～20 px，不要太宽 |
| 旋转角度 | 与目标边缘方向一致 | 可在图像上直接旋转 ROI |

### 主要参数

| 参数 | 含义 | 推荐值 |
|------|------|--------|
| Count（卡尺数量） | 沿路径等间距部署的卡尺数 | 100（默认），边缘短时可减小 |
| Edge Thr | 梯度阈值 | 100（默认）；对比度低时降到 30～50 |
| Polarity（极性） | 检测哪种边缘方向 | `Dark→Bright`：暗到亮边；`Bright→Dark`：亮到暗边；`Both`：两种都检测 |
| Edge Select | 每把卡尺取哪个边缘 | `Strongest`：取最强（推荐）；`First`/`Last`：取第一/最后 |
| Min Valid Ratio | 有效卡尺最低比例，低于则 NG | 0.5（默认） |

### 模式选择

#### 单边模式（Single Edge）
- 测量目标：**边缘位置** + **直线度**
- 极性选 `Dark→Bright` 或 `Bright→Dark`（明确方向）
- 结果：所有有效边缘坐标列表；直线度 = 各点到拟合直线的最大垂直偏差（像素）
- 若出现多条平行边缘（ROI 太宽）：**收窄矩形短轴**，确保只覆盖目标边缘

#### 双边模式（Width）
- 测量目标：**两侧边缘间距（工件宽度）**
- 极性选 `Both`
- 算法自动配对最近的正/负梯度，输出平均宽度（像素）
- 若出现多个有宽度的目标（ROI 覆盖多个间距）：**收窄 ROI 只包含一个目标**，否则配对会出错

### 输出结果

| 输出 | 说明 |
|------|------|
| 有效卡尺数 / 总数 | 显示 `N/M`，N 低说明边缘不明显或 ROI 偏移 |
| 宽度（Width 模式） | 两侧边缘平均间距（像素） |
| 直线度（Straightness） | 最大偏差（像素），越小越直；-1 表示点数不足 |
| PASS / NG | 有效比例 ≥ Min Valid Ratio 且直线度 ≤ 设定上限则 PASS |

### 典型操作步骤

1. 选择算法 **Caliper**，打开图像
2. 拖拽矩形 ROI 覆盖目标边缘，调整旋转角与边缘平行
3. 选择 Polarity（单边方向明确时选单方向）
4. 调整 Edge Thr，使有效卡尺数 ≥ 总数的 80%
5. 若需要直线度测量，勾选 **Straightness** 并设置上限
6. 点击 **▶ Run**，查看绿色边缘点和结果

### 常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| 有效卡尺数为 0 | Edge Thr 太高或 ROI 没覆盖边缘 | 降低 Edge Thr；检查 ROI 位置 |
| 宽度测量值随平移变化 | Polarity=Both 但 ROI 覆盖的不是同一对边缘 | 收窄 ROI 只包含目标边缘对 |
| 直线度异常大 | 存在噪声卡尺 | 提高 Edge Thr；降低 Min Valid Ratio 使噪声点排除 |
| Bright→Dark 识别结果异常 | 极性与实际边缘方向相反 | 换成 Dark→Bright 或 Both |

## 三、角点检测（Corner Detect）

### 功能说明

在 ROI 内检测图像的角点（Shi-Tomasi / Harris / FAST），输出按响应强度降序排列的角点坐标列表。  
推荐场景：检测矩形工件的四个角点、定位 L 形特征。

### ROI 设置

角点检测使用**矩形 ROI**（可拖拽四个角点调整大小）：

- ROI 默认居中于图像
- 建议 ROI 包含整个目标对象（如整块矩形工件），使算法能看到完整边界
- **不要让 ROI 只覆盖角点附近**，否则边界掩码会失效

### 检测器选择

| 检测器 | 特点 | 推荐场景 |
|--------|------|----------|
| **Shi-Tomasi**（默认） | 稳定、对工业场景泛用 | 矩形工件角点、绝大多数场景 |
| Harris | 对旋转不变，但参数更复杂 | 高精度角点定位 |
| FAST | 极快，但无响应强度值 | 实时检测、精度要求低 |

### 主要参数

| 参数 | 含义 | 推荐值 |
|------|------|--------|
| Max Corners | 最多返回角点数 | 矩形四角：**4**；多角点场景按需设置 |
| Min Distance | 两个角点的最小间距（px） | 设为目标最小角间距的 80%；默认 100 px |
| Quality Level | 相对最强角点的最小质量比 | 0.05～0.3；越高越严格，噪声越少 |
| Min Response | 绝对响应值下限 | 0（不过滤）；噪声多时设 0.01～0.05 |
| Subpixel | 亚像素精化 | 建议开启（精度提高到 0.1 px 级） |

### 边缘掩码（关键噪声抑制）

| 选项 | 含义 | 建议 |
|------|------|------|
| **Edge Mask**（开启） | 仅在图像边缘附近检测角点，排除平坦区域噪声 | 始终开启 |
| **Largest Region**（开启，推荐） | 找最大亮区域的轮廓边界作为掩码 | **亮色工件 + 暗色背景**时开启；能完全排除小噪声颗粒 |
| Canny Low / High | 仅 Largest Region=关闭 时生效，Canny 边缘阈值 | 150 / 300（高对比度场景） |

> **最常见问题根因**：图像中存在小亮斑/噪声颗粒，其边缘的角点响应值高于真实角点。  
> **解决方案**：开启 Edge Mask + Largest Region → 只在最大对象的轮廓边界上检测，噪声颗粒被完全排除。

### 转角角度过滤（Min Corner Angle）

| 参数 | 含义 | 推荐值 |
|------|------|--------|
| **Min Corner Angle** | 最小转角角度（°） | 矩形四角：25°；检测更小角度时降低 |

检测器有时在圆形轮廓上找到"假角点"（圆弧曲率不为零，导致局部像素量化为角点）。  
`Min Corner Angle` 过滤器测量候选点在轮廓上的局部转角：  
- 真实矩形角点 ≈ 90°  
- 圆弧上的量化噪声 ≈ 5°～20°  

设置 25° 可有效区分圆形和矩形，同时不误滤真实角点。  
设为 **0** 可关闭此过滤器。

### 常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| 检测到噪声颗粒上的角点 | Largest Region 未开启 | 开启 Largest Region；适当提高 Quality Level |
| 矩形的四个角只找到 2～3 个 | Min Distance 太大 | 降低 Min Distance（使角点间距条件宽松）；增大 Max Corners |
| 圆形边缘被当成角点 | 圆弧量化产生假角点 | 设置 Min Corner Angle 25°～45° |
| 角点坐标不精确 | Subpixel 未开启 | 开启 Subpixel Refine |

## 四、Blob 分析（Blob Analysis）

### 功能说明

Blob Analysis（连通区域分析）在 ROI 内通过**二值化 + 连通域统计**，找到所有符合条件的亮/暗区域（Blob），并输出每个 Blob 的面积、圆度、长短轴、质心等几何属性。

**典型应用场景：**
- 计数（焊点数量、螺孔数量、芯片管脚数）
- 尺寸检测（元件面积是否在规格范围内）
- 形状筛选（区分圆形焊点和矩形贴片）
- 存在性检测（目标是否出现在指定位置）

### ROI 设置

Blob Analysis 使用**矩形 ROI**：

- ROI 应包含感兴趣的 Blob 目标区域
- 建议适当留边，避免 Blob 被 ROI 边界截断

### 主要参数

#### 二值化

| 参数 | 含义 | 推荐值 |
|------|------|--------|
| Threshold | 灰度阈值（0 = Otsu 自动） | 0（自动）；亮暗对比明显时手动设置 |
| Polarity | 检测亮 Blob 还是暗 Blob | **Bright**：在暗背景中找亮区域；**Dark**：在亮背景中找暗区域 |

#### 形状过滤

| 参数 | 含义 | 推荐值 |
|------|------|--------|
| Min Area | 最小面积（px²） | 根据目标尺寸设置，过滤小噪声 |
| Max Area | 最大面积（px²） | 过滤过大的连通域（如整块背景） |
| Min Circularity | 最小圆度（0～1，圆形=1） | 0.7～0.9（筛选圆形焊点）；0（不过滤） |
| Min/Max Aspect Ratio | 长短轴比（≥1） | 1.0～1.5（近圆形）；1.0～∞（不限） |
| Max Count | 最多返回 Blob 数 | 根据目标数量上限设置 |

### 输出结果

| 输出 | 说明 |
|------|------|
| 找到 N 个 Blob | 满足所有过滤条件的连通域数量 |
| 质心 (cx, cy) | 各 Blob 重心坐标 |
| 面积 Area | 像素面积（px²） |
| 圆度 Circularity | 4π·面积/周长²，越接近 1 越圆 |
| 长短轴比 Aspect Ratio | 最小外接旋转矩形长轴/短轴 |

### 典型操作步骤

1. 选择算法 **Blob Analysis**，打开图像
2. 拖拽 ROI 覆盖目标区域
3. 选择 Polarity（目标是亮区域选 Bright，暗区域选 Dark）
4. Threshold 设为 0（自动），观察二值化效果
5. 设置 Min/Max Area 过滤噪声和背景
6. 若需筛选圆形：设置 Min Circularity 0.7～0.9
7. 点击 **▶ Run**，绿色框标注找到的 Blob

### 常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| Blob 数量过多（包含噪声） | 阈值太低或 Min Area 太小 | 提高 Threshold；增大 Min Area |
| 漏检目标 | Polarity 错误或 Min Area 太大 | 检查 Polarity；减小 Min Area；降低 Threshold |
| 相邻目标合并为一个 | 目标间距不足 | 使用形态学腐蚀或减小 Max Area 上限以拆分 |
| 圆形过滤掉矩形元件 | Min Circularity 太高 | 降低 Min Circularity；或设为 0 关闭圆度过滤 |

## 五、黄金模板（Golden Template）

### 功能说明

Golden Template（黄金模板差分）将当前图像与一张预先录制的"标准良品"参考图像对齐后，逐像素做灰度差分，超过阈值的区域标记为缺陷。

**典型应用场景：**
- PCB 焊点比对（检查漏焊、短路、偏移）
- 印刷标签检查（文字缺陷、墨迹不均）
- 屏幕坏点检测（亮点/暗点）
- 贴片元件方向检查（元件极性反转）

### 算法原理

```
参考图（黄金模板） → ┐
                      ├─ 图像对齐（ECC / FeatureBased）→ 差分图 → 阈值化 → 连通域分析
待检图（当前图像） → ┘
```

1. **对齐**：消除相机抖动、工件轻微偏移带来的位置误差
2. **差分**：`diff = |template - aligned_scene|`（双向）或 `diff = template - min(template, scene)`（仅检测变暗）
3. **阈值化**：Otsu 自动或手动阈值，得到缺陷二值掩膜
4. **连通域**：统计缺陷区域的位置和面积

### 参数说明

#### 模板配置

| 参数 | 含义 | 操作 |
|------|------|------|
| Template File | 参考图像文件路径 | 点击 `...` 加载一张已知良品图像（BMP/PNG/JPG） |
| Align mode | 对齐方式 | 见下表 |
| Motion model | ECC 运动模型（仅 ECC 模式下显示） | 见下表 |

**对齐方式：**

| 模式 | 原理 | 适用场景 |
|------|------|----------|
| **None** | 不对齐 | 相机固定、工件位置精确重复 |
| **ECC**（推荐） | 增强互相关，亚像素精度 | 允许轻微平移/旋转，绝大多数场景 |
| **Feature-Based** | ORB 特征点 + 单应矩阵 | 工件有较大形变或旋转 |

**ECC 运动模型：**

| 模型 | 参数维度 | 适用场景 |
|------|----------|----------|
| **Translation** | 2（X/Y 平移） | 图像已近似对齐，只需补偿微小位移 |
| **Euclidean**（默认） | 3（平移 + 旋转） | 工件可能有微小旋转，推荐默认 |
| **Affine** | 6 | 存在缩放或剪切（光学畸变、机械倾斜） |

#### 差分参数

| 参数 | 含义 | 推荐值 |
|------|------|--------|
| Diff Threshold | 灰度差阈值（-1 = Otsu 自动） | -1（自动）；噪声多时手动提高（30～80） |
| Diff direction | 双向 / 仅变暗 | **双向**（默认）：检测增亮和变暗；仅变暗：缺失/脱落材料 |
| Morph close size | 形态学闭运算核大小 | 5（默认）；0 = 关闭；增大可填充 Blob 内空洞 |
| Min Defect Area | 最小缺陷面积（px²） | 20（默认）；增大可过滤噪声点 |
| Max Defect Area | 最大缺陷面积（px²） | 1000000（默认）；减小可排除对齐误差造成的大面积假缺陷 |

### 典型操作步骤

1. 采集或加载一张已知良品的参考图像
2. 选择算法 **Golden Template**，点击 `...` 加载该参考图
3. 将待检图像设为当前图像
4. 选择 Align mode：
   - 普通场景选 **ECC + Euclidean**
   - 若图像位置固定精确，可选 **None**（速度最快）
5. Diff Threshold 设为 -1（Otsu 自动）
6. 点击 **▶ Run**，查看差分高亮区域（红色矩形）
7. 若噪声多（出现大量小红框）：提高 Diff Threshold 或增大 Min Defect Area
8. 若漏检缺陷：降低 Diff Threshold 或改为 **None** 对齐（消除对齐误差引入的假差分）

### 常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| 整图到处是缺陷 | 对齐失败（图像差异太大） | 换用 Feature-Based；检查模板是否与待检图同类 |
| 边缘处大量误报 | 对齐残差（轻微位移未补偿） | 改用 ECC 对齐；增大 Min Defect Area |
| 缺陷漏检 | Diff Threshold 太高 | 降低阈值；改为 -1 自动 |
| 运行速度慢 | ECC 迭代多（大图） | 选 Translation 模型；或缩小 ROI |
| 对齐失败（ECC 不收敛） | 初始偏移太大 | 换用 Feature-Based；或物理固定工件位置 |

### ROI 使用说明

> **ROI 的作用**：将比较范围限定在指定矩形区域内，场景图仅裁剪出 ROI 区域后再与模板对比；模板文件的尺寸应与 ROI 大小相匹配（代码会自动 `resize`，但尺寸一致效果更佳）。

**典型 ROI 用法：**
1. 在良品图上，框选需要检测的感兴趣区域（如 PCB 上的某个焊盘区域）
2. 从同一良品图截取该区域，保存为模板文件（*.png）
3. 将 ROI 设置为与截图相同的位置和大小
4. 检测时系统自动裁剪场景图的同一区域与模板做差分

> **注意**：算法不做滑窗移动。ROI 是固定窗口，模板与 ROI 一一对应。

### 多角度支持

| 对齐模式 | 支持角度范围 | 说明 |
|----------|-------------|------|
| None | 0° | 不补偿旋转，要求工件固定放置 |
| ECC Translation | ~0° | 只补偿平移 |
| ECC Euclidean（默认） | ±10~15° | 补偿平移 + 旋转，适合大多数场景 |
| ECC Affine | ±15°（带缩放/剪切） | 存在光学畸变时选用 |
| Feature-Based | 任意角度 | ORB 特征点 + 单应矩阵，适合大角度/大形变 |

### 输出结果

| 输出 | 说明 |
|------|------|
| No defects | 差分区域面积均在 Min/Max Defect Area 范围外 → 良品 |
| DEFECT FOUND: N regions | 检出 N 个缺陷连通域 |
| #i: area=A at (x, y) | 第 i 个缺陷的面积（px²）及质心坐标（ROI内坐标已自动转换为全图坐标） |
| 红色矩形框 | 叠加在全图上标注每个缺陷位置 |

### 常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| 整图到处是缺陷 | 对齐失败（图像差异太大）| 换用 Feature-Based；检查模板是否与待检图同类 |
| 边缘处大量误报 | 对齐残差（轻微位移未补偿） | 改用 ECC 对齐；增大 Min Defect Area |
| 缺陷漏检 | Diff Threshold 太高 | 降低阈值；改为 -1 自动 |
| ROI 外区域出现缺陷框 | 旧版本（ROI 未生效）| 已修复：ROI 现在正确裁剪场景后再比较 |
| 运行速度慢 | ECC 迭代多（大图或 ROI 过大） | 缩小 ROI；选 Translation 模型 |
| 对齐失败（ECC 不收敛） | 初始偏移太大 | 换用 Feature-Based；或物理固定工件位置 |

## 六、通用操作说明

### ROI 交互

| 操作 | 效果 |
|------|------|
| 拖拽 ROI 内部 | 平移 ROI |
| 拖拽矩形 ROI 的四个角句柄 | 调整大小（四角均可独立拖拽） |
| 拖拽环形扇形 ROI 的圆心 | 平移扇形 |
| 调整参数控件数值 | ROI 图形同步更新 |

### 结果状态

| 颜色 | 含义 |
|------|------|
| 绿色结果文字 | PASS：检测成功且满足阈值 |
| 红色结果文字 | NG：检测失败或不满足阈值 |

### 调参流程建议

```
1. 先调 ROI → 确保覆盖目标且不包含多余区域
2. 再调 Edge Thr（卡尺）/ Quality Level（角点）→ 控制噪声灵敏度
3. 最后调 RANSAC / Min Inliers → 控制鲁棒性
```
